# 01 — Requirements (Krishna, 2026-11-24; final unless Krishna changes them)

## Functional — on-device skills (must work offline)

| # | Skill | Requirement |
|---|---|---|
| R1 | **Safe reader** | Reads text (signs, labels, documents, handwriting). Speaks numbers, doses and prices only when verified; otherwise refuses or says "not sure". *Exists (Phase 1).* |
| R2 | **Computation / math** | E.g. "what is 15 × 27" from a whiteboard or from speech. The answer must be exact. |
| R3 | **Translation** | "Translate this to English", from text in view or from speech. Language list to be decided (Indian languages are the priority). |
| R4 | **Chat** | Open conversation, poems. Has a persona with emotional tone (a "Donna"-style assistant). |
| R5 | **Visual Q&A** | "What am I holding?", plus follow-ups ("what colour is it?") using short-term memory. States its uncertainty. |
| R6 | **Online fallback** | If the local model can't answer, search the web over Wi-Fi (or Bluetooth to the phone, used purely as a modem), then answer **with the source named**. Weather, news etc. use search or an API plus GPS location. |
| — | **Out of scope** | Coding assistance. |

## Interaction

- **R7 — Wake:**
  - "Hey Friday" gives an **immediate chime**, then processing.
  - Saying the wake phrase once must be enough.
  - The touch button stays in the plan.
- **R8 — Latency:**
  - Wake-to-chime: <80 ms awake (plan.md).
  - Time to first spoken word: target about 1.2 s (plan.md, to be measured in Phase 2).

## Research ambition (Krishna's direction)

- **R9 — Our own student model.**
  - Pretrained small models are used as **teachers**.
  - FRIDAY runs **our own distilled student**: multi-teacher, multi-skill distillation.
  - Combining off-the-shelf models alone is **not** the thesis contribution.
- **R10 — Research experiments.** These must be actually tested; failure is a valid result to report.
  - Weight editing / model editing: does it work on our student, and how?
  - "Train big, then prune and distil small."
- **R11 — Compute.** Use the Kaggle GPU quota (about 30 h/week, 2× T4) as much as is useful.

## Non-negotiable safety rules (from Phase 1)

1. No generated numbers. Doses, prices and numbers come **only** from the extractive reader or from deterministic computation (a math parser). They are never generated by a language model.
2. Web answers must name their source. Medical numbers from the web come with the source and a caution.
3. Nothing is claimed in docs or the thesis without committed run output.
